# Metasploitable 2 Security Assessment

## Overview
Cybersecurity lab for vulnerability assessment and penetration testing using Metaspolitable2 and kali Linux. 

## Objectives
- Identify exposed services
- Perform vulnerability assessment
- Analyze security risks
- Recommend remediation
- Verify security improvements

## Lab Environment
- Kali Linux
- Metasploitable 2
- VirtualBox
- Isolated virtual network

## Methodology
1. Reconnaissance
2. Enumeration
3. Vulnerability identification
5. Remediation
6. Verification

## Vulnerability Findings

[V-01: FTP Service ](findings/V-01-FTD.md) 

## Key Recommendations
- Disable unnecessary services
- Replace insecure protocols
- Apply security patches
- Restrict network access

## Disclaimer
This project was conducted in an isolated lab environment
using an intentionally vulnerable machine.
